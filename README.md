# UniLoop 校園循環

UniLoop 是以大學生為對象的二手物品交換與買賣平台展示作品，讓閒置物品在校園間繼續流轉。

🌐 [線上展示](https://uniloop-campus-market-1029.shinkirou20230101.chatgpt.site)

## 主要功能

- 瀏覽、搜尋、篩選與排序商品，查看商品詳情與多張照片。
- 註冊展示帳號、登入、編輯個人資料與查看個人賣場。
- 上架、編輯及管理商品，設定買賣、交換或贈送方式。
- 商品問答、站內聊天、通知與通知提示音。
- 模擬交易申請、接受、拒絕、取消、雙方確認及交易紀錄；同一商品可收到多位買家申請。

## 執行方式

這是一個靜態網頁，不需要安裝套件。下載專案後，以本機 HTTP 伺服器提供 `dist` 資料夾，例如在專案根目錄執行：

```bash
python -m http.server 8000 --directory dist
```

接著用瀏覽器開啟 `http://localhost:8000/`。主要網頁程式位於 `dist/index.html`，圖片素材位於 `dist/products/` 和 `dist/product-sheet.png`。

## 展示限制

這是課程用展示原型。帳號、商品、聊天、通知與交易資料存放於目前瀏覽器，無後端或跨裝置同步；清除瀏覽資料可能造成紀錄遺失。密碼沒有正式系統應有的安全保護，請勿使用常用或重要密碼，也請勿輸入真實個人敏感資訊。交易、付款及校園身分驗證均非真實服務。

通知提示音受瀏覽器自動播放限制，通常須先操作頁面才可播放，網站關閉後也不會收到通知。
